# Prompt History Record

## Command
```
sp.specify # /sp.specify

## Phase I — Spec 2: Add Todo Item

---

## Project
**The Evolution of Todo — Phase I: In-Memory Python Console Application**

Focus: Implement the **Add Todo** functionality as the first core feature of Phase I.
Goal: Enable users to create tasks in memory via the console using **Claude Code–generated Python**, without any manual coding.

---

## Target Audience
Students building Phase I in-memory CLI Todo app using Claude Code and Spec-Kit Plus.

---

## Objective
Allow the user to **add a new Todo item** with title and description, and store it in memory with a unique ID and default incomplete status.

---

## Success Criteria
- User can add multiple Todo items in a single session
- Each Todo has:
  - Unique ID
  - Title (required)
  - Description (optional)
  - Status: incomplete by default
- Todo items appear when listed in-memory
- No persistence (data is lost after program exits)
- Generated Python code adheres to **clean code principles** and project structure

---

## Constraints
- ❌ No manual Python code
- ❌ No file or database persistence
- ❌ No AI integration
- ❌ No leftover test/debug code
- ❌ Empty or whitespace-only titles are rejected

---

## Inputs
- Todo title (required)
- Todo description (optional)

---

## Outputs
- New Todo item stored in memory
- Unique ID assigned automatically
- Default status: incomplete

---

## Edge Cases
- Empty title → reject and display error message
- Whitespace-only title → reject and display error message
- Duplicate titles allowed (IDs remain unique)

---

## Tasks
1. Define in-memory data structure (list or dictionary) to store Todos
2. Implement "Add Todo" console command
3. Assign unique ID for each new Todo
4. Set default status to incomplete
5. Validate input (non-empty title)
6. Confirm addition by printing a success message in console
7. Ensure added Todo is retrievable via the "View" feature (Spec 3)

---

## Outputs (Files to Generate)
- `/specs/phase-1/spec-2.md` → this spec
- Python source code in `/src/todo/add_todo.py` generated by Claude Code
- Update `/src/todo/model.py` to include Todo data structure

---

## Definition of Done
- User can run `python main.py` and add Todo items
- Console displays confirmation for each addition
- Todos are stored in-memory and retrievable immediately
- Code is **fully generated by Claude Code**, no manual edits
 BUT FIRST READ THE PROJECT COMPLETLY
```
